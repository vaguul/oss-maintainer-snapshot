# Contributing

Thanks for considering a contribution.

This project is intentionally small and read-only. Changes should keep the CLI
easy to inspect, easy to run locally, and safe to use in public maintenance
workflows.

## Development

```bash
npm install
npm test
```

## Pull requests

Good pull requests usually include:

- a focused problem statement
- tests for CLI parsing, report formatting, or filtering behavior when behavior changes
- README or example updates when usage changes
- no write actions against GitHub issues, pull requests, repository settings, or comments

## Scope

In scope:

- clearer reports
- safer CLI validation
- read-only GitHub queue metadata
- CI and GitHub Actions examples
- documentation for maintainer workflows

Out of scope:

- posting comments automatically
- editing issues or pull requests
- changing repository settings
- storing tokens or secrets
